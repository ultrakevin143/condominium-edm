# Bern workspace

Mode: Operate. Fictional condominium staff reconcile source records, inspect data issues and browse authorized resident information. Pipeline is the initial tab, confirmed by the user. Compact headings, filters and tables carry the work; no hero, decorative graphs or summary-card grids.

Use a light stone surface, dark charcoal type and one deep teal accent. All colors are CSS tokens. Use a single sans-serif scale (14px body, 12px secondary, 24px page title), 4px spacing increments and tabular numerals. A narrow property identity rail joins a compact top navigation; smaller screens wrap navigation and scroll tables inside their boundaries. Data and forms have loading, empty, error and success states.

Use shadcn/ui-style source controls (Radix Slot and Tabs, class-variance-authority) with Tailwind, semantic tables and labelled native form inputs. One Lucide icon set. Keyboard focus is visible. No sensitive credentials appear in the UI. Inline editors keep context; all real changes need a reason. Fictional data is labelled throughout.
